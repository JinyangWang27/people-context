# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, keep discussion about the work, and never post other people's
personal data — this is a project about people, and the same care applies to the people in its issue tracker.

Report unacceptable behavior privately to the maintainer at the email listed in
[SECURITY.md](SECURITY.md). Reports are handled confidentially.
